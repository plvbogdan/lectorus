# Lectorus

Lectorus — это современная платформа для создания и обучения курсам по машинному обучению, которая автоматически преобразует Jupyter-ноутбуки в интерактивные лекции с удобной навигацией по темам.

## Основные фичи

- 📝 **Загрузка Jupyter-ноутбуков** (формат .ipynb или .json)
- 🔄 **Автоматический парсинг** — ноутбук разбивается на разделы и темы
- 🎨 **Чистый интерфейс** — удобное отображение кода и markdown
- 👤 **Регистрация/авторизация** — чтобы создавать свои курсы
- 📚 **Навигация по лекции** — быстрое переключение между темами

## Как запустить

### 1. Клонируем репозиторий
```bash
git clone https://github.com/plvbogdan/lectorus.git
cd lectorus
```
### 2. Создаем файл .env в корне
```env
SECRET_KEY=your-secret-key
DB_NAME=lectorus_db
DB_USER=lectorus_user
DB_PASSWORD=your-password-here
```
### 3. Запускаем через Docker 
```bash
docker-compose up
```

Готово! Приложение доступно на http://localhost:3000

## Как пользоваться

1. Зарегистрируйся на платформе
2. Создай новый курс, укажи название и тему
3. Загрузи Jupyter-ноутбук (.ipynb файл)
4. Система автоматически разобьёт его на лекции:
   - Ячейки с markdown → текст лекции
   - Ячейки с кодом → блоки кода с подсветкой
   - Заголовки (#, ##) → разделы навигации

5. Поделись ссылкой на курс с учениками
